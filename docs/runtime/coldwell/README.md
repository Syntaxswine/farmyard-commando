# Coldwell runtime integration

Feature branch: `codex/coldwell-runtime`, based on reviewed main `251bf8094b5f9ebe44208443084c1a6d6658512a`. The architect owns main integration and Pages promotion. This branch supplies the complete optional runtime and Coldwell Recon. Native acceptance on its proposed head remains a release gate.

The first checkpoint adds atomic, SHA-verified complete-bundle loading, source-preserving deterministic collision conversion, optional provider registration, bounded horizontal/floor residency, and the exact native narrow phase behind the reused Nautilus static broad phase. It retains the complete 240 × 240 source, all 23 silo datums, support roofs, all 31 native stairs and the 11 independent authored rigs. Data/source integrity, transforms, real openings/holes/curves, vertical obstruction and independent door/cover poses have focused checks. Source archives remain preserved in the verified intake; the unmodified reduced geometry, source pair and notices needed for reproducible adapters are checked in under `sources/coldwell`.

See [reuse map](reuse.md) and [art boundary](art-boundary.md). The reused world schema disallows commas in IDs. A small internal broad-phase ID map preserves original AFT source/edge IDs while satisfying that schema; no upstream validator is relaxed. Native envelopes are only candidates: ray and body hits use the supplied game triangles and existing Three math. The source game LOD records at most 0.004552 m shaft chord error; it is not a newly guessed rectangular approximation.

The next checkpoint integrates the reviewed artist commits through `15364b8d2c4103e4c3fb325a8c574e08284b7e57` (runnable assets `372c09c23754c00fede6b1cc927063204421e4f5`), preserving their authorship. All 31 complete stair intervals pass continuous body sweeps in both directions; gait-sized movement stays continuous and uses 3D walked distance. The original silo transform implementation is imported byte-for-byte for collision poses. Three surface-door colliders now consume the artist's verified source rig exports, bringing the total to 14 independent rigs. The private `coldwell-preview.html` uses actual FieldView, the shared floor widget, canonical camera/picking, bounded asynchronous art and awaited disposal. Its controls are explicitly a non-playable geometry preview.

Coldwell-specific native CI now exercises all eight proving views, actual FieldView, phone viewports, original rig controls, repeated disposal and real standard/depth/distance shaders. It must pass on the proposed head before visual approval. Nearby floor counts are development settings until profiled; software WebGL does not establish real-device mobile performance. Canonical decoded collision bytes reproduce across zlib versions; shipped compressed bytes still have their own verified SHA.

The complete runtime now serves navigation, perception, shots, grenades, blast, flame and persistent fire through the same source geometry. Camera, picking, animal/loot/burn/blast presentation and the shared interaction hand retain absolute height and stable floor IDs. The host's native-mesh fog bridge applies existing unseen/remembered/visible policy per floor while composing original paint and shadow hooks. AFT's audited interior mask assumes legacy raster rooms and 3 m layers, so it cannot be applied unchanged to these meshes. Underground inspection clips ceilings above the selected floor; roof inspection exposes the supplied support roofs.

Spatial save format 2 uses canonical cell centres at `n + .5` with raster indices `0…239`. Fog, minimap, cone masks, persistent fire and map-edge saves use that same origin. The minimap follows the inspected floor; actors/loot above its cutaway stay hidden and ray picks stop at the selected support. Legacy integer-centred maps retain their original rules. The pathfinder derives a lower bound from original stair lengths and refuses floors with no authored connection before searching.

All 14 machinery controls have safe, reachable source-supported operating positions. Ordinary doors cost 1 AP in combat; powered controls default to 2 AP; exploration is free. The simulation validates the complete moving-body sweep before spending AP, rejects removal of occupied bridge support (including fallen bodies and persistent fire), then locks movement/turn advancement during the accepted transition. Saves retain source identity, independent poses, transition progress, actor/route heights, floor-qualified exploration and loot. Restore rebinds immutable geometry without relocation or transient effect replay. Native tread/bridge picking and partial-stair routes preserve continuous height. Static walking links cache geometry checks while testing live bodies independently; enemy replanning has a bounded 128-node budget.

Coldwell Recon begins at the first supplied spawn outside contact, places six guards on verified support, requires the gatehouse duty sheet and B5 records from a shared chest, and returns to the supplied exit. Supplies are optional and clearing guards is unnecessary. A public-command acceptance controller completes the route and retains legally played checkpoints for native UI checks. The quiet `coldwell-traversal` route remains unlisted; its acceptance URL exposes only read-only snapshots/projection. The separate preview stays explicitly non-playable. All five required provider capabilities are now implemented on this feature branch. Released mission replay baselines remain unchanged.

Native CI additionally exercises actual door actions, selected-floor stair movement, phone Take All and game save/resume using those checkpoints. Evidence includes exact SHA, backend, renderer diagnostics, screenshots, trace, video and cleanup receipts. Inspect that evidence before visual approval. Software WebGL establishes no real-device mobile performance claim.

Proving, gatehouse/area weapons, stair traversal and records each run as a separate bounded native scenario. Each owns its browser, progress report, trace/video and verified port cleanup; the HTTP fixture has an eighteen-minute automatic expiry. This keeps a long proving run from consuming a gameplay scenario's budget and preserves evidence before cleanup.

Original rig math and renderer are reused; no donor build/viewer script runs. No shared user browser setting is changed and no local preview/browser helper is retained.
