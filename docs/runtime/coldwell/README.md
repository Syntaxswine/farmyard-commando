# Coldwell runtime integration

Feature branch: `codex/coldwell-runtime`, based on reviewed main `251bf8094b5f9ebe44208443084c1a6d6658512a`. Architect owns integration and promotion. This branch is active implementation; no Coldwell operation is enabled until its required providers and gameplay acceptance pass.

The first checkpoint adds atomic, SHA-verified complete-bundle loading, source-preserving deterministic collision conversion, optional provider registration, bounded horizontal/floor residency, and the exact native narrow phase behind the reused Nautilus static broad phase. It retains the complete 240 × 240 source, all 23 silo datums, support roofs, all 31 native stairs and the 11 independent authored rigs. Data/source integrity, transforms, real openings/holes/curves, vertical obstruction and independent door/cover poses have focused checks. Source archives remain preserved in the verified intake; the unmodified reduced geometry, source pair and notices needed for reproducible adapters are checked in under `sources/coldwell`.

See [reuse map](reuse.md) and [art boundary](art-boundary.md). The reused world schema disallows commas in IDs. A small internal broad-phase ID map preserves original AFT source/edge IDs while satisfying that schema; no upstream validator is relaxed. Native envelopes are only candidates: ray and body hits use the supplied game triangles and existing Three math. The source game LOD records at most 0.004552 m shaft chord error; it is not a newly guessed rectangular approximation.

The next checkpoint integrates the reviewed artist commits through `15364b8d2c4103e4c3fb325a8c574e08284b7e57` (runnable assets `372c09c23754c00fede6b1cc927063204421e4f5`), preserving their authorship. All 31 complete stair intervals pass continuous body sweeps in both directions; gait-sized movement stays continuous and uses 3D walked distance. The original silo transform implementation is imported byte-for-byte for collision poses. Three surface-door colliders now consume the artist's verified source rig exports, bringing the total to 14 independent rigs. The private `coldwell-preview.html` uses actual FieldView, the shared floor widget, canonical camera/picking, bounded asynchronous art and awaited disposal. Its controls are explicitly a non-playable geometry preview.

Coldwell-specific native CI now exercises all eight proving views, actual FieldView, phone viewports, original rig controls, repeated disposal and real standard/depth/distance shaders. It must pass on the proposed head before visual approval. Nearby floor counts are development settings until profiled; software WebGL does not establish real-device mobile performance. Canonical decoded collision bytes reproduce across zlib versions; shipped compressed bytes still have their own verified SHA.

Remaining gates: full navigation/combat/fog adoption in actual operation commands; authoritative safe rig transactions and deterministic saves; private playable route and Coldwell Recon; complete actual FieldView traversal/interaction/save acceptance. No required capability or Coldwell operation is advertised by the preview checkpoint. Released mission replay baseline files remain unchanged.
