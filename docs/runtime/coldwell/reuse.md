# Coldwell reuse map

Read-only source audit: Nautilus working copy `8c4670450cb2b38c1e1abd811d633c22de9e2b7c` (released v0.8.0); AFT `AnimalFactory3D/game` at `131fde44c0c3a77decfc612f0b06bc31312b35b8`; existing Farmyard and pinned AFT/editor snapshots; unchanged silo collection `3b9d4004a7e51e5d345cded068fc46eab2f320a2`. No donor checkout is modified. The byte-preserved optional Nautilus closure and notices have a separate manifest; existing AFT/editor pins remain untouched.

| Source | Farmyard use | Demonstrated boundary / smallest adapter |
| --- | --- | --- |
| Nautilus v0.8.0 `world-core/state.js`, `validation.js`, `queries.js` | Reuse strict metre coordinates, 32-floor schema and immutable BVH/queryBounds as the custom provider's broad phase. | `compileWorld` explicitly implements AABB panels/solids only; `findSupport` returns the AABB top. It cannot test an annular hole or actual triangle. Keep exact authored polygon/triangle checks after candidates; never report broad envelopes as exact collision. |
| Nautilus v0.8.0 `floor-navigation/index.js`, `dom.js`, `style.css` | Reuse complete floor-selection, character-follow/contact tracking and input lifecycle. | Host supplies canonical IDs/heights and rendering bands. The widget does not supply navigation/support. |
| Supplied silo `packages/silo/three.js`, `mesh.js`, exported game mesh/rigs | Artist reuses the existing model/material/pose machinery and all 11 rig IDs. Coder consumes unchanged exported triangles and semantics, matching native transforms/pose units. | `transformSiloRigPoint` already defines hinge degrees and slider travel. Its blueprint explicitly leaves swept body clearance, navigation, operating costs and save adoption to consumers; the optional renderer's `setRigPose` is presentation only. The adapter validates accepted actions using these same poses. |
| Farmyard `interactions.js`, operation/save storage | Reuse hand targeting, reach checks, action costs, loot/clue/objective/extraction and effect replay suppression. | Add optional provider hooks for height/reach, native rigs, safe sweeps and source identity. Preserve flat-mission behavior. |
| Farmyard `world-grid.js`, `render-residency.js`, FieldView lifecycle | Reuse 24 m blocks, 3 × 3 residency, bounded camera, owned resource disposal and model loading. | Adapt canonical half-metre origin once and add nearby-floor bands. Preserve authoritative offscreen state. |
| AFT `hybrid-world.js` / `environment.js` in existing snapshots and audited game | Reuse material, edge, prop and dimension rules, including fences, windows, dirt, trees and roof slabs. | Existing floor support is AABB/legacy tile geometry; stairs are eight-riser tiles with a different footprint from the supplied two-flight 12-riser stair. Source-native stair geometry must remain unchanged. |
| AFT `core/maps.js`, `core/engine.js`, `core/projectiles.js` | Retain compatible policy patterns; Farmyard already reuses character/weapon/perception rules. | AFT stepping is tile/layer based and projectile code uses 3 m tactical layers; substituting it would change the requested continuous 2.12 m traversal. Keep Farmyard AP/gait rules and adapt their accepted 3D distance. Closed doors use existing opensTo edge policy, not the silo's continuous hinge/slider sweep. |
| Nautilus `runtime-core/lifecycle.js`, item state/actions | Audit existing module startup and transactional patterns. | Module lifecycle manages service start/rollback, not moving geometry. Item state manages carried/thrown items, not bridge support or door poses. No equivalent dynamic-geometry state machine is supplied in released v0.8.0. Use existing Farmyard transactions with a small rig-state sidecar. |

Accuracy: source-native geometry/poses preserve the artist's actual openings and stair pitch. Efficiency: existing static broad phase plus exact local checks avoids a second general physics engine or editor runtime. Narrative: existing Farmyard scouting, clues, loot and extraction support Coldwell Recon without imposing a new inventory/rules system. These are code-based choices; mobile performance remains to be measured.
